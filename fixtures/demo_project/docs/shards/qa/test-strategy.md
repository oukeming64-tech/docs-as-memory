# 测试策略

## 概述

测试代码在 `tests/`，按金字塔分层。

## 分层

- 单测（70%）：纯函数与领域逻辑，禁止起服务、禁网。
- 集成（25%）：API 层，用测试库，鉴权走真实中间件。
- E2E（5%）：只覆盖登录、下单两条黄金路径。

## 门槛

- 全仓行覆盖率 ≥ 80%；`src/auth/` 单独要求 ≥ 90%。
- 新增代码覆盖率低于门槛 CI 直接红。

## CI 集成

- PR：单测 + 集成（约 6 分钟）；E2E 只在主干跑。
- flaky 测试挂起隔离，两周内不修复就删除，不允许「重试到绿」。

## 边界

- 快照测试只用于组件库 base 层。
- 测试数据用 factory，禁止从生产导数据。
